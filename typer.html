ABOUT AETHER TYPE
AETHER TYPE is a fast, single-file browser typing game built to turn keyboard practice into an arcade loop with readable pressure, quick recovery, and replayable flow.
Author
Dr BennyT
Format
Offline HTML game prototype designed to scale into a larger project structure.
Core Loop
See target, type cleanly, break pressure waves, and survive long enough for the system to push back.
Controls
Type letters to attack, Escape to pause, F8 to mute, and Tab for an early hyperdrive boost when unlocked.
